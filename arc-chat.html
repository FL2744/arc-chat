Setup & troubleshooting

Start this interface using start.command (macOS/Linux) or run python helper.py after installing requirements and Playwright Chromium. Opening this HTML by itself shows the interface but cannot connect to ARC.

If the launch form changes, fill it in manually in the helper’s browser. Connect ready session attaches automatically. To use a Jupyter tab opened manually, click Attach automatically. If several different servers are open, select a session from the buttons shown. If login expires, sign in again. Do not rerun a cell after losing connection until you have checked its state in Jupyter.

HTML results run in an isolated preview with scripts disabled. Download interactive maps and open trusted files locally. Jupyter widgets are not supported. Notebook cells and outputs are saved remotely; dialogue can be exported separately.
