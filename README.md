# ARC Chat v0.3.0 downloads

These files are the API-free distribution mirror for ARC Chat v0.3.0.
They were built by GitHub Actions from commit 4da87236c4539d6ec8c48542df296baa6b07a642 after the release test gates passed.

- ARC-Chat-Windows.zip - Windows bootstrap
- ARC-Chat-macOS.zip - macOS bootstrap app
- ARC-Chat-Linux.zip - Linux bootstrap
- ARC-Chat-source.zip - source archive

The bootstrap packages require internet access on first launch and install their runtime dependencies/Chromium locally.
The much larger self-contained Windows/macOS bundles are retained as CI artifacts rather than normal Git objects.
