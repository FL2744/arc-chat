# Licensing status

No project-wide open-source license has been selected in this repository yet.

Publishing source code on GitHub does not by itself resolve copyright ownership or grant a general reuse license. Before an institutional/public open-source release, the project owner and the appropriate Virginia Tech/project stakeholders should determine:

1. who owns the relevant copyright;
2. whether Virginia Tech, individual contributors, a course/project sponsor, or another entity must approve licensing;
3. which license is appropriate for source, bundled third-party components, and documentation;
4. what notices/attributions must ship in binary distributions.

Until that decision is documented, release notes should describe ARC Chat as a preview/source-available project rather than claiming a specific open-source license.
